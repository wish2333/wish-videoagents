# 图片准备清单 - Animemory #0 我的耽美阅读史

## 说明

- 所有图片放入 `public/reading-history/` 目录
- 在 `slides-data.ts` 中通过 `imageSrc` 字段引用（Remotion 组件自动用 `staticFile()` 解析）
- 空字符串会显示灰色占位卡片（居中显示作品名）
- 通过 `cardSize` 字段可覆盖默认卡片尺寸（默认按 works 数量自动计算）

## 图片尺寸规范

| 类别 | 显示尺寸 | 比例 | 适用范围 |
|------|----------|------|----------|
| 竖向封面（默认） | 400x530 | 3:4 | 非广播剧类单张/双张作品 |
| 横向封面（默认） | 260x347 | 3:4 | 3张以上多图展示 |
| 广播剧封面 | 320x320 | 1:1 | s2-n5 至 s4 全部广播剧作品 |
| CV 照片 | 200x200 | 1:1 | s3-n2 受役/攻役 |
| 特殊尺寸 | 由 cardSize 指定 | 自定义 | s0-n1 Given 等 |
